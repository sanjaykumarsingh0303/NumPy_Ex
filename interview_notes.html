ndarray

What is a NumPy array?

An ndarray is a block of values that all have the same type. A Python list holds pointers to separate objects. An ndarray holds the numbers themselves, packed together, plus a shape that says how to read them as rows and columns.

Is a matrix the same as a multidimensional array?

A matrix is a 2D array. A multidimensional array can have 1, 2, 3, or more axes, so every matrix is an ndarray, and a 3D array is not a matrix.

NumPy also has an old np.matrix type that is always 2D. In an interview, say you use a normal ndarray and @ for matrix multiplication.

Why NumPy is fast

Why is scores + 5 faster than a Python loop?

  • The loop runs in compiled C. Python is called once for the whole array.
  • Values sit next to each other in memory, so the CPU can load many at once.
  • The dtype is fixed, so the inner loop does not check the type of each element.
  • Matrix products go through a tuned BLAS library.

The gap shows up when the array is large. For five numbers it is tiny.

Why is itemsize 8 and nbytes 80?

int64 is 8 bytes. There are 10 elements, so the array occupies 80 bytes. Itemsize is one element. Nbytes is the whole array.

What do real, imag, flat, and flatten do?

real and imag are the real and imaginary parts. For an integer array, imag is all zeros. flat is an iterator over the elements. flatten() returns a new 1D copy.

Shape and 3D arrays

What does np.arange(24).reshape(2, 3, 4) mean?

24 numbers folded into 2 blocks, 3 rows in each block, 4 values in each row. The product of the dimensions must equal the number of elements: 2 * 3 * 4 = 24.

How do you know an array is 3D?

Count the nested lists. In ndarray_basics.py, g is two blocks, each block has two rows, and each row has three numbers. g.shape is (2, 2, 3) and g.ndim is 3.

g[0]        # first block, shape (2, 3)
g[0, 1]     # one row, [10, 12, 13]
g[1, 2, 3]  # would be out of range; last value is g[1, 1, 2] == 113

A nested for peels off one axis per loop. The outer loop gets a block, the middle loop gets a row, and the inner loop gets one number.

How do you label a printed array with an f-string?

The f sits against the quote, and the expression goes inside braces:

print(f"first student: {scores[0]}")

Boolean indexing

How do you keep only the scores that pass?

A comparison returns a True/False array of the same shape. Using that array as an index keeps the True positions. From boolean_index.py:

passed = scores >= 75
scores[passed]          # only the passing scores
scores[scores < 80]     # the condition can sit inside the brackets

Broadcasting

What is broadcasting?

NumPy stretches a smaller array so an operation can run against a larger one, without you writing a loop. From broadcasting.py:

  • marks + 5 adds 5 to every cell.
  • marks + grace, with grace shaped (3,), adds one bonus per column.
  • marks * [[1], [2]] leaves row 0 as it is and doubles row 1.

Sizes line up from the right. A dimension of 1 can stretch. Dimensions that differ and are both greater than 1 do not broadcast.

Axis

What do axis 0 and axis 1 mean?

Axis is the direction that gets combined, and that direction disappears from the result. For the table in axis_stats.py:

[[70, 80, 90],
 [60, 75, 85],
 [90, 88, 92]]

mean(axis=0) walks down each column: [73.33, 81, 89]. One number per subject.

mean(axis=1) walks across each row: [80, 73.33, 90]. One number per student.

mean() with no axis uses every cell and returns one number, 81.11.

Stacking

How do you join two arrays?

From stacking.py. Two arrays of shape (2, 2):

  • np.vstack((a, b)) places b under a. Shape (4, 2). Same as concatenate(..., axis=0).
  • np.hstack((a, b)) places b to the right. Shape (2, 4). Same as concatenate(..., axis=1).

The sizes on the other axis must already match.

Matrix product and element-wise product

What is the difference between @ and *?

@ is the matrix product: rows times columns. The inner sizes must match. In matmul.py, qty is (2, 3) and prices is (3,), so qty @ prices is (2,) and equals [80, 110].

* multiplies matching positions. It does not combine a row with a column. x * y and x @ y are different results.

Reshape and transpose

What does reshape change?

Only the view of the same numbers. np.arange(12).reshape(3, 4) works because 3 * 4 = 12. A reshape whose product does not match the element count raises an error.

grid.T swaps rows and columns, so (3, 4) becomes (4, 3). ravel() returns a 1D view when the memory is contiguous. flatten() always returns a copy.

Sort, where, and clip

How do sort, argsort, where, and clip differ?

From sort_where.py, with scores = [92, 85, 90, 64, 78, 55]:

  • np.sort(scores) returns the values from low to high. The original array stays in place.
  • np.argsort(scores) returns the indexes that would produce that order. scores[np.argsort(scores)] matches np.sort.
  • np.where(scores >= 75, "pass", "fail") picks one label per element.
  • np.clip(scores, 60, 90) pulls every value into the range 60 through 90. 55 becomes 60. 92 becomes 90.

argsort is the one to mention when a second array must follow the same order as the first.

Pitfalls worth mentioning

Why did random.random((2, 2)) fail?

Python’s random.random() takes no arguments and returns one float. NumPy’s np.random.random((2, 2)) accepts a shape and returns an array of values in [0.0, 1.0). np.floor(10 * that) then gives floats such as 6.0, still floats because floor returns floats.
